# item-service

7번 강의 `스프링 MVC - 웹 페이지 만들기` 실습을 따라가기 위한 초기 프로젝트입니다.

아직 요구사항 분석 이후의 예제 코드는 넣지 않았고, 스프링 부트 프로젝트 뼈대만 준비된 상태입니다.

## 실행

PowerShell에서 아래 명령으로 실행할 수 있습니다.

```powershell
.\gradlew.bat bootRun
```

## 구성

- Group: `hello`
- Artifact/Project Name: `item-service`
- Package: `hello.itemservice`
- Packaging: `jar`
- Dependencies: `Spring Web`, `Thymeleaf`, `Lombok`
