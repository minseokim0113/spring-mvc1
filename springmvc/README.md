# springmvc

6번 강의 `스프링 MVC - 기본 기능` 실습을 위한 시작 프로젝트입니다.

## 실행

PowerShell에서 아래 명령으로 실행할 수 있습니다.

```powershell
.\gradlew.bat bootRun
```

실행 후 `http://localhost:8080` 에 접속하면 시작 페이지를 확인할 수 있습니다.

## 구성

- Group: `hello`
- Artifact/Project Name: `springmvc`
- Package: `hello.springmvc`
- Packaging: `jar`
- Dependencies: `Spring Web`, `Thymeleaf`, `Lombok`
